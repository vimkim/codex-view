# Third-party assets

## MathJax 3.2.2

The packaged MathJax browser distribution is vendored under
`src/codex_view/static/mathjax/`. It is licensed under Apache-2.0; its license
is included in that directory. The full component distribution is included so
optional TeX and accessibility components can load without a CDN.

- Project: https://github.com/mathjax/MathJax
- Distribution: https://www.npmjs.com/package/mathjax/v/3.2.2
- Source package version: 3.2.2

Python dependencies and their exact resolved versions are recorded in `uv.lock`.
